# 통합과학2 OX

휴대폰으로 푸는 통합과학2 OX 카드 학습 앱입니다. 완자 통합과학2(2022 개정) 범위, 1,415문항.

## 기능
- 범위 선택: 중단원 → 소단원 (선택한 범위는 이 기기에 자동 저장되어 다음에 열어도 유지)
- 구분 선택: 중요 / 고난도 / 지엽 / 일반
  - 중요: 서로 다른 2개 학교 이상의 기출에 나온 내용
  - 고난도: 계산·순서 연쇄·여러 조건 비교가 필요한 내용 (출제자 판단)
  - 지엽: 수치·제도명·긴 나열 등 암기하기 어려운 세부 내용 (출제자 판단)
  - 일반: 나머지
- 출제 대상: 전체 / 안 푼 문항 / 오답노트
- 카드 풀기: 오른쪽으로 밀면 O, 왼쪽으로 밀면 X (아래 O·X 버튼도 가능)
- 해설 보기: 카드마다 바로 / 다 풀고 한꺼번에
- 결과: 점수, 소단원별 정답률, 틀린 것만 다시 풀기
- 오답노트: 틀린 문항이 자동으로 쌓이고, 두 번 연속 맞히면 빠짐
- 같은 개념 문항은 한 세트에 한 장만(설정에서 끌 수 있음)
- 기록 내보내기/불러오기(기기를 바꾸거나 브라우저 데이터를 지울 때 대비)

기록은 학생 각자의 기기 브라우저(localStorage)에만 저장됩니다. 로그인·서버 없음. 시크릿 모드나 브라우저 데이터 삭제 시 사라질 수 있으니 중요한 기록은 내보내기 하세요.

## 문항 수정
`data/items.json` 한 파일만 고치면 됩니다.

| 필드 | 뜻 |
|---|---|
| `c` | 문항 코드 (예: `03-A-12` = 중단원 03, 소단원 A, 12번) |
| `a` | 정답 `O` / `X` |
| `q` | 문제 |
| `e` | 해설 |
| `p` | 완자 쪽 (예: `p.10`) |
| `k` | 완자 표시 (`탐구`, `암기해`, `주의해`, `1등급` 또는 빈칸) |
| `g` | 같은 개념 묶음 |
| `b` | 출판사 (해당 교과서에만 있는 내용일 때) |
| `l` | 구분 (`중요` / `고난도` / `지엽` / `일반`) |
